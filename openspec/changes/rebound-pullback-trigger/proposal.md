## Why

计算器页和详情页一直把“反弹买入 / 回落卖出”当作真实的反弹确认来展示（“需跌破 ¥X”“已达步长 · 待反弹”），但回测引擎实际用的是固定价格：买入价 = 上次成交价 − 步长 + 反弹，日内最低价只要触及就按这个固定价成交，不要求先跌破步长线，也不看真实的最低点和反弹。结果是：价格跌得比步长线更深时，成交价被高估（例如上次成交 5、步长 1、反弹 0.2，当天最低 3.6 并反弹到 3.8，引擎仍按 4.2 成交），反弹和回落两个参数也退化成了“把买卖间距各缩短一点”。用户预期的是真正的反弹买入、回落卖出。

## What Changes

- 买入改为“跌破步长线 → 从最低点反弹”：自上次成交起跟踪最低价（跨日）；当最低价 ≤ 上次成交价 − 步长，且某天最高价 ≥ 最低点 + 反弹时买入，成交价为最低点 + 反弹（限制在当天最低价与最高价之间）。
- 卖出对称：自上次成交起跟踪最高价；最高价 ≥ 上次成交价 + 步长，且某天最低价 ≤ 最高点 − 回落时卖出，成交价为最高点 − 回落（同样限制在当天价格区间内）。
- 每次成交后清空跟踪；每个交易日最多一笔，同日买卖都满足时买入优先（沿用现有约定）；建仓日不参与。
- “预计下次买入 / 卖出”在已跌破（突破）步长线、等待反弹（回落）时，显示为“最低点 + 反弹”（“最高点 − 回落”）；尚未触及步长线时仍为 上次成交价 ∓ 步长 ± 反弹。
- 所有已保存记录按新规则重算；备份的快照随规则版本升级重算（规则版本 4 → 5），保证备份对比仍是同一口径。
- 计算器页说明文字、详情页提示同步更新。
- **BREAKING**：回测成交价与成交日会变化，历史结果与旧版本不可比。

## Capabilities

### New Capabilities
- `grid-trigger-rules`: 网格买入/卖出的触发规则：跌破/突破步长线、从极值反弹/回落、成交价、跨日跟踪、每日一笔与买入优先，以及“预计下次买卖价”的取值。

（无。）
